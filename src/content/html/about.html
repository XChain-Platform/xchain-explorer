XChain Platform is an open-source multi-chain platform which has been built by the Dankest, LLC developers to enable advanced cross-chain token functionality on Bitcoin, Litecoin, Dogecoin, and other blockchains. The XChain Platform is based on the open-source Broadcast Token Naming System (BTNS).

The Broadcast Token Naming System (BTNS) is a bleeding-edge experimental protocol to play around with token functionality on Bitcoin and other blockchains.
