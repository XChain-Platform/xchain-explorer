The XChain Platform is a open-source multi-chain platform which has been built by the Dankest, LLC developers to enable advanced token functionality on Bitcoin, Litecoin, Dogecoin, and many other blockchains. The XChain Platform comes with a complete set of features unlike any other including, cross-chain functionality, a decentralized Exchange (DEX), Dispensers (vending machines), a oracle interface, and more!
