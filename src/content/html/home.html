The XChain Platform is an open source token platform for any blockchain, built by Dankest, LLC. It is live today on Bitcoin, Litecoin, and Dogecoin, with no sidechains and no bridges. One protocol carries tokens, a decentralized exchange (DEX), dispensers, smart contracts, staking, oracles, and cross-chain calls, and this explorer is where you browse that activity on every supported network.
